# Nodal Atlas

Nodal Atlas — быстрый визуальный редактор для мышления картами: идеи, сущности и связи оформляются в интерактивный граф с нодами, группами, страницами, изображениями и заметками.

## Цели продукта

- **Быстрый флоу работы**: мгновенное создание нод и связей, плавное масштабирование/панорамирование.
- **Поддержка итеративного мышления**: undo/redo, история действий, автосохранение.
- **Удобный обмен данными**: сохранение/загрузка в JSON.

## Core-функциональность (MVP)

1. Редактор графа:
   - создание, выделение, перемещение и удаление нод;
   - создание и удаление связей (edges);
   - группы (group containers) и page-ноды;
   - поддержка изображений и заметок в нодах.
2. Навигация:
   - zoom in/out;
   - pan canvas (включая удержание Space).
3. Организация графа:
   - авто-раскладка (auto-layout).
4. История действий:
   - undo/redo с сохранением последовательности операций.
5. Данные:
   - экспорт/импорт JSON;
   - автосохранение локального состояния.

## Горячие клавиши (Hotkeys)

- `V` — Select tool
- `N` — Node tool
- `E` — Edge tool
- `G` — Group tool
- `P` — Page node tool
- `Space` (удержание) — Pan mode
- `Delete` / `Backspace` — удалить выделенное
- `Ctrl+Z` — Undo
- `Ctrl+Y` или `Ctrl+Shift+Z` — Redo

## Fast Thinking System

### 1) Quick-mode ноды

Минималистичный формат ноды для моментального ввода мысли без лишних полей и модальных окон.

### 2) Scratch-режим

Временные (черновые) ноды для гипотез:

- быстрый вход в черновой слой;
- commit/rollback черновых изменений в один шаг.

### 3) Ghost-link flow

При протяжке связи из ноды пользователь может в том же жесте создать дочернюю ноду и сразу связать её.

### 4) Mini-toolbar на ноде

Контекстная панель на ноде с действиями:

- `Child`
- `Link`
- `Dup`
- `State`

### 5) Мгновенная история действий

Низколатентное логирование операций для комфортного циклического мышления с быстрым undo/redo.
